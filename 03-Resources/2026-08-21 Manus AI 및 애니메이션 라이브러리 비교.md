## Manus (manus.im)

중국 스타트업 Butterfly Effect(구 Monica.Im)가 2025년 3월 출시한 **범용 자율 AI 에이전트**. "손"을 뜻하는 라틴어에서 이름을 땀 — 가상 리눅스 샌드박스 안에서 여러 시간짜리 복합 작업을 프롬프트 하나로 자율 실행하는 것이 핵심 컨셉.

- **구조**: Planner / Executor / Verifier 멀티에이전트 아키텍처. 브라우저 조작, 코드 실행, 스프레드시트·슬라이드·PDF 생성을 체이닝해 몇 시간짜리 세션을 자율 진행.
- **주요 기능**
  - 지속 로그인 세션을 유지하는 브라우저 자동화
  - DB·인증 로직까지 포함한 웹앱 프로토타입 통째로 생성
  - "Wide Research" — 여러 서브에이전트를 병렬로 돌려 다수 출처를 동시에 조사
  - 빠른 응답용 Chat Mode
  - 모델 티어: Manus 1.6 Lite / 1.6 / 1.6 Max
- **적합한 용도**: "경쟁사 10곳 가격 조사해서 표로 정리" 같이 사람 개입 없이 끝까지 자율 실행해도 되는 작업에서 강점.
- **과금**: 크레딧 기반 구독제 — 복잡한 작업일수록 크레딧 소모 빠름.
- **2025-12-29 소식**: **Meta가 Manus 인수 발표**.

## anime.js / GSAP / react-spring 비교 (JS 애니메이션 라이브러리)

| | anime.js | GSAP | react-spring |
|---|---|---|---|
| 성격 | 경량 SVG 특화 tween 라이브러리 | 산업 표준, 스크롤·타임라인 애니메이션 풀 플랫폼 | 물리 기반(spring) 선언형 라이브러리 |
| 용량 | v4 기준 약 17KB (min+gzip) | 코어 약 25KB, 플러그인 추가 시 증가 | (별도 수치 미확인) |
| 성능 | v4에서 GSAP과 비슷한 수준까지 개선(이전 버전은 열세) | 대량 동시 애니메이션에서도 성능 우수, 최고 수준으로 평가됨 | — |
| React 통합 | 지원하지만 부가적 | 프레임워크 무관(agnostic) | React 네이티브, 가장 매끄러움 |
| 대표 플러그인/특징 | 없음, 린 앤 포커스드 | ScrollTrigger, SplitText 등 강력한 플러그인 생태계 | 없음, spring 물리엔진 자체가 핵심 |
| 주간 다운로드(npm) | 777K | 2.55M | 1.06M |
| GitHub 스타 | 67K | 24K | 29K |

**선택 기준**
- 스크롤 연동·타임라인 중심의 복잡한 연출 → **GSAP**
- 가벼운 SVG·기본 tween 위주 → **anime.js**
- React UI에서 자연스러운 물리감 있는 전환(모달, 카드 등) → **react-spring**
