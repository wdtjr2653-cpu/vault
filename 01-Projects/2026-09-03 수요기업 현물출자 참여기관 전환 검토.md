## 결론 — 참여(공동)기관 등록이 맞다

산업통상부 공고 제2026-536호 **3-1** 원문:
> 수요기업의 경우 **정부지원사업비 지원 없이 참여가 가능**하며 이 경우 **기관부담사업비 중 현물(참여인력 인건비 등)로 구성**할 수 있음
> * "수요기업"이란 … 성능 평가 및 검증 역할을 하는 **참여기업**

현물은 기관부담사업비의 구성요소 → 기관부담사업비는 8-1 표의 **수행기관(주관+공동)** 만 계상 → **공동기관 등록 필수**.
「9. 수요기업 확약서」 양식 하단에 이미 **"수요기업 대표자 (인) / 공동책임자 (인)"** 란이 있는 것도 같은 방향의 근거.

제출서류표 비고 기준: 3(참여의사확인서)·4(개인정보동의서)·5(서약서)·7(책임자 재직증명서)·8(신청자격 적정성 확인서) = **전체(주관+공동)**. 2(사업자등록증)·10(재무제표) = 영리기업. 6(기업부설연구소 인정서)는 주관만.

## 반드시 인지할 함정 3가지

**① 지원제외 리스크가 컨소시엄 전체로 전이된다 (최대 리스크)**
확약서만 낼 때는 심사 대상이 아니지만, 공동기관이 되면 공고 4-3 사전지원제외 심사 대상이 된다. 부도·체납·채무불이행·회생/파산·**3년 연속 부채비율 500%↑**·**자본전액잠식**·감사의견 거절 중 하나라도 걸리면 **과제 전체 지원제외**. 중고차 매매상사·소규모 법인은 위험. 설립 5년 미만이면 부채비율 항목은 적용 제외.
→ 재무 상태가 불확실하면 **공동기관으로 올리지 말고 확약서만 받는 편이 안전**. 대표님께 보고 필요.

**② 현물을 넣으면 "현금 13%" 요건이 깨진다**
공고 3-1은 컨소시엄 단위로 정부지원 ≤70% / 기관부담 ≥30% / **기관부담 중 현금 ≥13%**.
현물 X를 더하면 A/E(정부지원 비율)는 좋아지지만 B/D(현금 비율)는 나빠진다.
v1.1 기준(A 2,000,000 / B 103,500 / C 689,700 / D 793,200 / E 2,793,200, A/E=71.60%, B/D=13.05%):

| 현물 X | A/E | 추가로 필요한 현금 |
|---|---|---|
| 64,000 | 70.00% ✅ | 약 7,900 |
| 100,000 | 69.16% | 약 12,600 |
| 200,000 | 66.82% | 약 25,600 |

추가 현금 ≈ **0.13 × X**. 수요기업은 현금 0원이 원칙이므로 **모나/퀀텀이 메워야 한다**.
→ 부수 효과: 기존의 **A/E 71.6% 초과 문제가 현물 64,000천원 이상이면 자동 해소**된다. (※ v1.2_연구비수정 반영 후 재계산 필요)

**③ 법인실명인증이 진짜 병목**
공고 6항 — 기관·인력 신규가입의 **법인실명인증·개인실명확인은 서울신용평가정보 사무처리 시간(~18:00) 내에만** 가능. 미인증 시 온라인 접수 자체가 진행되지 않음. 마감이 오늘 18:00이므로 **서류 사인보다 IRIS 인증이 먼저**.
참여연구원 **국가연구자번호**도 본인이 직접 가입·실명인증해야 발급 → 현장에서 즉석 처리 필요.
참여율은 타 과제 포함 **합계 100% 초과 불가**.
