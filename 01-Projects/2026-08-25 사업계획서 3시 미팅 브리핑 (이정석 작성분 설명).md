#project/ai-sprint #type/briefing

15시 회의에서 이정석 작성분에 대해 설명 요청이 올 경우 대비한 섹션별 브리핑. 근거 숫자와 출처, 예상 질문 포함.

## 1. 요약문·1-2 과제의 배경 및 필요성

- 장황 문단을 개조식(리드 + 하위 불릿)으로 재구성. 핵심 논리: **정보 비대칭(중고EV 배터리 상태를 알 수 없음) → 안전성 우려 → 정책·제도 시행 → 실측 기반 진단·가치산정 필요**.
- **배터리 안전성 인증제 근거**: 자동차관리법 개정으로 2025-02-17 시행, 1년 유예 후 **2026년 2월부터 의무 적용**(국토교통부 보도자료 확인). 단, 인증제는 **신차 제작 단계** 인증이고 우리 서비스는 **유통·중고 단계** 진단 — "제도가 만든 안전성 검증 흐름이 중고 시장으로 확장되는 길목"이라는 보완 관계로 설명.
- 도표 2장: 전기차 누적 등록대수 추이(출처: 국토교통부), 전기차 화재 발생 추이(출처: 소방청).

## 2. 4-1 국내·외 기술과 시장 현황

**국내**: BMS(OBD) 조회 + 외관점검 중심 초기 시장. 경쟁사 — 피엠그로우(실사용 데이터 기반 SOX 진단·안전알림), 아이카(셀 전압·온도 편차 기반 SOH·SOC). **차별점: 이동형 충·방전 '실측' + 시세·재사용 가치 통합 잔존가치 산정은 국내 미확인.**
- 중고전기차 거래량: **2026년 상반기 전년 동기 대비 +103.6%** (국내 중고차 거래량 증감률 도표).

**국외**: AVILOO(오스트리아) — 주행시험·셀모델 기반 PREMIUM Test, ML 기반 FLASH Test / Recurrent(미국) — 완성차 텔레매틱스 API 기반 Battery Score. **공통 한계: 실차 충·방전 없이 추정 의존, 거래현장용 이동형 하드웨어 + 가치평가 통합 서비스는 미확인.**
- 시장 수치 3종: EV 배터리 상태진단시스템 **CAGR 11.6%** / 배터리 테스트·검사·인증 시장 **2034년 748억$** / 중고차(세컨드라이프) 배터리 시장 **12.4억$(2025) → 325.2억$(2035)** — 글로벌 도표는 GMI·The Insight Partners 원본 수치로 교체함(추정치 아님).

## 3. 4-4 경제적 성과 창출계획 (주관기관) — 숫자 산출 근거

문서에 산출 근거를 명시해 둠. 질문 시 이 순서로:
- **수익 모델**: 진단 1건 50,000원 (리포트 + 디지털 인증서 발급 포함).
- **처리 능력**: 1대당 1일 8건 × 월 20영업일 × 12개월 = **연 1,920건/대**. (1건당 진단 60분 이내 — 4-3 표준 SOP의 "60분 이내 급속 계측"과 일관, 준비·대기 포함 보수적으로 8건/일)
- **설비 증설**: 사업기간 내 3대(5,760건/년) → 종료 후 3년 내 **55대(96,000건/년)**.
- **점유율**: 국내는 **중고전기차 연간 거래 대수 대비** 1%(2026) → 21%(2029). 판매량 2,000 → 86,400건, 국내매출 1억 → 43.2억원.
- **해외**: 2028년부터 진출, 단가 $40, 3,000→8,000건.
- **투자**: 3년간 약 30억원(장비 증설 + AI 추론 서버), 장비 가동률 상승으로 **개발 종료 후 1년 차 흑자 전환, 3년 차 영업이익률 17%**. 부동산 투자 없음(임차).

## 4. 3-4 일자리 창출 (주관기관)

- **과제 기간(12개월) 내 직접 채용은 청년 연구인력 1명** — AI 진단·가치산정 모델 개발 전담, 데이터 분석·모델 학습·장비 SW 등 핵심 직무 배치.
- 그 외는 **상용화 이후 전망으로 구분**해 서술: 장비 3→55대 증설에 따른 현장 서비스 인력 순차 채용, 전국 거점 확산에 따른 권역별 운영 인력, 협회 보수교육 연계 간접 고용(내연기관 정비인력의 전동화 전환).
- 질문 예상 "1명뿐인가?" → 과제 기간이 1년이라 직접 채용은 1명이 현실적이며, 상용화 로드맵(55대)이 실질적 고용 창출 경로임을 강조.

## 5. 4-5 사회적 가치 창출 계획

- 비전: "신뢰할 수 있는 배터리 정보로 공정한 중고전기차 거래와 지속가능한 자원순환 실현" + 실행전략 4개(진단·AI·인증 연계 / 전국 거점 확산 / 재사용·재활용·탄소저감 / 민간 데이터 순환생태계).
- 직접 가치: 정보 비대칭 해소·분쟁 예방(디지털 인증서), 간접 가치: 자원순환(재사용·재활용 선별), 지역(이동형 서비스로 접근성 격차 완화).
- 세부계획1: 인증서 기반 소비자 보호(위·변조 방지, 비식별화), 세부계획2: 자원순환 생태계 연계(협회 협력 표준화·제도 대응).

## 6. 공동기관 취합 현황 (오늘 오전 작업)

- **협회(KAAT)**: 2-2 목표·내용, 2-3 일정, 3-3 편성도(남경근 실장 외 1명), 3-4(연구인력 1명 정규직 채용), **4-3 표준화 전략**(EU 배터리 여권·UN GTR No.22 대비 국내 기준 부재 → SOP 4단계 → S~D 5등급 → 단체표준→국토부 건의→ISO 로드맵, 24개 성능검사장·340여 협력망 실증), 7-1·7-3. 제출서류 6종(재무제표는 비영리라 해당없음).
- **퀀텀에이아이**: 2-2 플랫폼 목표·내용(통합 DB, REST API/WebSocket 연계 규격, 리포트 자동 생성, SHA-256 인증서 무결성), 2-3, 7-1(우창한 이사 + 참여자 10명), 7-3(매출 99.5억, 재무 3개년), 8-2/8-3(인건비 490,300천원·장비비 224,000천원), 별첨1 장비계획서 4건(AP 서버 2대 8,800만원 등). 제출서류 7종 완비.
- **미해결 2건 (이사님 확인 요청 중)**: ① 공동기관1 기관명 — 제출서류는 퀀텀에이아이 명의, 본문 곳곳 메타덱스터 잔존(교체 확정 여부 확인 필요), ② 퀀텀 측 **3-4 일자리·4-4 경제적 성과 미작성**(기업 작성 의무 항목) — 재요청 필요.
