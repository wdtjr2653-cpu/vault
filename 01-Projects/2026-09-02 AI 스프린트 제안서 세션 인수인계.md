## 기술 노하우 (HWP 편집 — 새 세션이 편집 작업 시 필수 숙지)

- **HWPX 직접 XML 편집**: zip 구조, `Contents/section*.xml`. 함정 3가지 — ① 행 복제 시 `<hp:linesegarray>` 반드시 제거, ② `<hp:ctrl>` 제거하면 파일 깨짐, ③ **MEMO fieldBegin이 든 셀은 전체 텍스트 재작성(set_cell)하면 파일 깨짐** → 메모 있는 행은 무수정으로 우회. mimetype는 STORED로 재압축.
- **HWP COM SaveAs 포맷 문자열**: docx는 "DOCX"가 아니라 **"OOXML"**. 한글 경로에서 저장 실패 → ASCII 임시 경로 경유.
- **HWP→Word 변환 최고 품질 경로**: 한글에서 PDF 저장 → Word로 `Documents.Open(pdf)` → `SaveAs2 FileFormat=16` (OOXML 직접·RTF 경유는 표/배경 깨짐 — 비교 실험 완료, PDF 경유 최종 채택)
- 공고 사업비 기준: 정부지원 ≤70% / 기관부담 ≥30% / 부담 중 현금 ≥13% (컨소시엄 단위), 간접비 ≤ 직접비 현금 5%, 연구수당 원칙 불가·예외 10%
- **보존 자산**: 작업 폴더의 `세션_인수인계_자산\`에 복사해둠 — `seal_jang.png`(장익황 도장), `sign_song.png`(송 대필 서명 — 여기서 생성한 유일본), `build12.py`/`build12b.py`(v1.2 빌드 스크립트, HWPX 편집 함정 우회가 코드에 반영됨), `comins.py`(HWP COM 도장 삽입). PDF 경유 Word 변환은 인라인 실행이라 스크립트 없음 — 위 방법 설명으로 재현
